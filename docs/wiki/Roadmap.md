# Roadmap até o MVP funcional

| Etapa | Escopo | Estado |
|---|---|---|
| R0 | fundação de dados, aplicações, documentos, versões e hashes | concluído |
| R1 | qualificação documental e diagnóstico por página | concluído |
| R2 | conversão, Markdown, pacote auditável e visualização | concluído |
| R3 | atos, artigos, anexos, ocorrências, adjudicações e release do corpus | em desenvolvimento |
| R4 | leitura integral, livro de cobertura e contexto C0 | planejado |
| R5 | execução das vinte variáveis C1-C20 | planejado |
| R6 | aprendizado supervisionado e métricas | planejado |
| R7 | integração C21 e validação C22 | planejado |
| R8 | relatório, referências e release municipal | planejado |
| R9 | ciclo completo operável pela interface | planejado |

## Próximo marco

O R3 deve permitir importar atos e artigos do Markdown convertido, vincular dispositivos às páginas de origem, identificar lacunas e duplicidades, inventariar anexos, registrar ocorrências e liberar uma versão imutável do corpus somente quando as não conformidades críticas estiverem resolvidas ou adjudicadas.

## Definição mínima de pronto

Corpus completo e auditado → C0 com cobertura integral → vinte variáveis documentadas → C21 integrada → C22 adjudicada → relatório rastreável → release versionado.
